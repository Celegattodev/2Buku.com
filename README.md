# 2Buku.com - Plataforma de Troca de Livros 📚

Bem-vindo ao **2Buku.com**, uma plataforma desenvolvida para facilitar a troca de livros físicos entre pessoas na mesma região. Nosso objetivo é oferecer uma solução prática, sustentável e econômica para leitores de todos os perfis expandirem suas bibliotecas de maneira colaborativa.

## 📖 **Visão Geral**

O **2Buku.com** permite que os usuários:
- Explorem uma ampla variedade de livros disponíveis para troca.
- Economizem significativamente, evitando gastos com a compra de livros novos.
- Contribuam para práticas sustentáveis, promovendo a reutilização de recursos.

## 🎯 **Escopo do Projeto**

**2Buku.com** foi projetado para:
- Democratizar o acesso à leitura.
- Incentivar a troca colaborativa de livros físicos.
- Conectar leitores com interesses semelhantes dentro de sua região.

## 👥 **Público-Alvo**

A plataforma atende diferentes perfis:
- **Leitores ávidos**: acesso sustentável a uma ampla gama de títulos.
- **Estudantes**: facilidade no acesso a materiais didáticos.
- **Pais**: opções acessíveis para renovar a biblioteca das crianças.
- **Colecionadores**: oportunidade de encontrar edições raras.
- **Leitores econômicos**: leitura acessível sem custos elevados.

## 🛠️ **Tecnologias Utilizadas**

- **Node.js**: Back-end.
- **Express.js**: Estrutura de aplicação web.
- **MongoDB**: Banco de dados.
- **HTML, CSS e JavaScript**: Front-end.
- **Middleware personalizado**: Para segurança e eficiência.

## 🚀 **Como Rodar o Projeto**

1. Clone o repositório:
   ```bash
   git clone https://github.com/Celegattodev/2Buku.com.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd 2Buku.com
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Configure as variáveis de ambiente no arquivo `.env` (exemplo disponível em `.env.example`).
5. Inicie o servidor:
   ```bash
   npm start
   ```
6. Acesse o projeto no navegador em [http://localhost:3000](http://localhost:3000).
