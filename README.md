O Buku é uma plataforma inovadora criada para facilitar a troca de livros usados, promovendo a leitura, a sustentabilidade e a conexão entre leitores. Aqui está um resumo do funcionamento:
 ✅ Os usuários podem navegar no catálogo e encontrar títulos de interesse.
 ✅ Enviam propostas ao proprietário do livro desejado.
 ✅ O proprietário é notificado por e-mail e pode aceitar ou recusar a troca.
 ✅ Com a troca confirmada, os contatos são enviados por e-mail, permitindo que os envolvidos organizem a logística de forma direta.

🛠️ Tecnologias utilizadas:
- Frontend: HTML, CSS, Bootstrap e JavaScript.
- Backend: Node.js com integração de APIs, como:
 - API do Google Books (para buscar os livros).
 - API do Google Translate (suporte multilíngue).
 - API Nodemailer (envio de notificações por e-mail).
 - API de localidades do IBGE (cadastro de localização).
 - Cloudinary (armazenamento de imagens na nuvem).
- Banco de dados: MySQL.
